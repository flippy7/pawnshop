## Початковий стан і захист

Початкові SHA-256 містяться в [protected-hashes.json](protected-hashes.json): 30 583 файли docs, specs/001, scripts, .tools, .specify/scripts і конституція (кеші __pycache__ не включалися). ## Команди та результати

Точні аргументи, робочі каталоги, фактичні й очікувані коди кожного процесу — [results.json](logs/results.json). Для кожної назви є окремі stdout.log і stderr.log у logs/. Версії середовища — java-version.txt і javac-version.txt. Компілювалися всі 10 файлів src/pawnshop.

```powershell
New-Item -ItemType Directory -Force out | Out-Null
javac --release 17 -encoding UTF-8 -d out src/pawnshop/*.java
java '-Dfile.encoding=UTF-8' '-Dsun.stdout.encoding=UTF-8' '-Dsun.stderr.encoding=UTF-8' -cp out pawnshop.Main all
java '-Dfile.encoding=UTF-8' '-Dsun.stdout.encoding=UTF-8' '-Dsun.stderr.encoding=UTF-8' -cp out pawnshop.Main verify
java '-Dfile.encoding=UTF-8' '-Dsun.stdout.encoding=UTF-8' '-Dsun.stderr.encoding=UTF-8' -cp out pawnshop.Main fault-check
```

## Виявлені й виправлені проблеми середовища

Перший запуск незацитованих -D-параметрів у PowerShell дав ClassNotFoundException для .encoding=UTF-8. Лапки виправили передавання аргументів; README, quickstart і контракт оновлено та повторно перевірено. Додаткова перевірка через jdeps з PATH спочатку використала старий Zulu 8; остаточний доказ отримано явним jdeps.exe із JDK 25.0.4. Ці діагностичні спроби не подаються як успішні перевірки продукту.
